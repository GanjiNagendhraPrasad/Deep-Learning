<h1 style="color:#8b5cf6;">🧠 What is Deep Learning?</h1>

<p style="font-size:18px;">
Deep Learning is a subset of 
<b>Machine Learning</b> that uses 
<b>Artificial Neural Networks</b> with multiple layers 
to learn patterns from data automatically.
</p>

<h1 style="color:#8b5cf6;">🧠 Artificial Neural Networks (ANN)</h1>

<p style="font-size:18px;">
Artificial Neural Networks are inspired by the human brain.
They consist of interconnected neurons that process information.
</p>

<div style="background:#111827; padding:25px; border-radius:15px; margin-top:20px;">

<h2 style="color:#22c55e;">📌 Components of ANN</h2>

<ul style="font-size:18px;">
<li>Input Layer</li>
<li>Hidden Layers</li>
<li>Output Layer</li>
<li>Weights</li>
<li>Bias</li>
<li>Activation Functions</li>
</ul>

</div>

<h2 style="margin-top:30px;">⚡ Forward Propagation</h2>

<p style="font-size:18px;">
Data moves from input layer → hidden layers → output layer.
The network calculates outputs using weights and activation functions.
</p>

<h2 style="margin-top:30px;">🔄 Backpropagation</h2>

<p style="font-size:18px;">
Backpropagation updates weights using error gradients to reduce loss.
It is the core learning mechanism in neural networks.
</p>

<hr style="border:1px solid #334155; margin-top:60px; margin-bottom:60px;">

<h1 style="color:#8b5cf6;">⚡ Activation Functions</h1>

<div style="display:grid; grid-template-columns:repeat(auto-fit,minmax(300px,1fr)); gap:25px;">

<div style="background:#1e293b; padding:25px; border-radius:15px;">
<h2>Sigmoid</h2>
<p>Outputs values between 0 and 1.</p>
<p>Used in binary classification.</p>
</div>

<div style="background:#1e293b; padding:25px; border-radius:15px;">
<h2>Tanh</h2>
<p>Outputs values between -1 and 1.</p>
<p>Better centered outputs.</p>
</div>

<div style="background:#1e293b; padding:25px; border-radius:15px;">
<h2>ReLU</h2>
<p>Most popular activation function.</p>
<p>Fast and computationally efficient.</p>
</div>

<div style="background:#1e293b; padding:25px; border-radius:15px;">
<h2>Leaky ReLU</h2>
<p>Prevents dead neuron problems.</p>
</div>

<div style="background:#1e293b; padding:25px; border-radius:15px;">
<h2>Softmax</h2>
<p>Used in multi-class classification.</p>
</div>

</div>

CNNs are specialized neural networks designed for image processing and computer vision tasks.

      ↓

      ↓
Activation Function
      ↓
Pooling Layer
      ↓
Feature Maps
      ↓

      ↓

Output

<h1 style="color:#8b5cf6;">📝 Recurrent Neural Networks (RNN)</h1>

<p style="font-size:18px;">
RNNs are designed for sequential data processing.
They remember previous information using hidden states.
</p>

<h2>📌 Applications</h2>

<ul style="font-size:18px;">
<li>Text Generation</li>
<li>Speech Recognition</li>
<li>Language Translation</li>
<li>Time Series Forecasting</li>
</ul>

<h2>⚠ Problems in RNN</h2>

<ul style="font-size:18px;">
<li>Vanishing Gradient</li>
<li>Exploding Gradient</li>
<li>Short-Term Memory</li>
</ul>

<hr style="border:1px solid #334155; margin-top:60px; margin-bottom:60px;">

<h1 style="color:#8b5cf6;">🧠 LSTM (Long Short-Term Memory)</h1>

<p style="font-size:18px;">
LSTM is an advanced version of RNN designed to solve memory problems.
</p>

<h2>📌 Components of LSTM</h2>

<ul style="font-size:18px;">
<li>Forget Gate</li>
<li>Input Gate</li>
<li>Cell State</li>
<li>Output Gate</li>
</ul>

<h2>📌 Advantages</h2>

<ul style="font-size:18px;">
<li>Handles Long Sequences</li>
<li>Better Memory Retention</li>
<li>Improved NLP Performance</li>
</ul>

<hr style="border:1px solid #334155; margin-top:60px; margin-bottom:60px;">

<h1 style="color:#8b5cf6;">⚡ GRU (Gated Recurrent Unit)</h1>

<p style="font-size:18px;">
GRU is a simplified version of LSTM.
It uses fewer gates and trains faster.
</p>

<h2>📌 Components</h2>

<ul style="font-size:18px;">
<li>Update Gate</li>
<li>Reset Gate</li>
</ul>

<hr style="border:1px solid #334155; margin-top:60px; margin-bottom:60px;">

<p style="font-size:18px;">
Transformers revolutionized NLP and modern AI systems.

<h2>📌 Core Concepts</h2>

<ul style="font-size:18px;">
<li>Self Attention</li>
<li>Multi Head Attention</li>
<li>Positional Encoding</li>
<li>Encoder Decoder Architecture</li>
